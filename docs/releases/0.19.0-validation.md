# NeLux 0.19.0 validation

Release baseline: PyTorch 2.14.0, torchvision 0.29.0, CUDA 13.2 torch wheels on
Windows/Linux, and `214torch` wheel ABI tags. Python 3.13 and 3.14 remain the
published targets. The macOS build uses CPU/MPS PyTorch.

## Local release checks

Windows, RTX 3090, Python 3.14.6, PyTorch 2.14.0+cu132, and FFmpeg 8.1.2-tas:

- Full `pytest tests tools/tests` run: **1,852 passed, 201 skipped, zero failures,
  zero expected failures**, in 308.53 seconds. Skips cover unavailable
  codec/hardware combinations, optional generated data, and wheel-only checks.
- The final 0.19.0 installed-wheel range gate passed **566 tests**, with 68
  documented skips, and passed the CPU/NVDEC corpus reference gate.
- Corpus: **596 checks**, across 21 file/backend/prefetch runs: 17 successes,
  three expected timestamp rejections, one explicitly unsupported backend.
- The CUDA-enabled build imports and decodes with **CPU-only PyTorch 2.14.0**.
- Wheel verification confirms the seven pinned FFmpeg libraries and their
  licence files are bundled. The wheel was tagged `214torch` before validation.

The first PyTorch 2.14 run exposed integer `frame_at` arguments being handled
as seconds. Explicit numeric dispatch fixed it; marker tests now distinguish
Python/NumPy integer indices from floating timestamps on both output backends.
Obsolete encoder expected-failure tests were replaced with checks of supported
float encoding/directory creation and actual invalid paths/layouts.

Local reproducible logs are under `build_test/torch214_full_final.log`,
`build_test/torch214_full_final.xml`, and `build_test/release019_gate/`. Use the
project's `.venv_torch214` environment for source tests; the rebuilt extension
requires PyTorch 2.14.x and will reject a 2.13 interpreter environment.

## Publication gates and scope

The release workflow builds Windows/Linux/macOS wheels for Python 3.13/3.14 and
runs each installed-wheel range gate before uploading artifacts. GitHub release
creation and PyPI publication depend on all platform builds succeeding. GPU
reference checks were run locally on the RTX 3090; other GPU generations require
separate validation.

The corpus remains synthetic regression evidence. These results do not establish
a population-wide 99.9% success rate. See [corpus validation](../corpus-validation.md)
for holdout sampling and the exact outcome definitions.
